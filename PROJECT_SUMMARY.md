# Dishook - Project Summary

## Overview

**Dishook** is a modern, production-ready Discord webhook manager web application built with vanilla HTML, CSS, and JavaScript. It features Material Design 3 styling, complete Discord Webhook API integration, and a fully responsive user interface.

## Getting Started

### Fastest Way

1. Visit: `https://artemishich.github.io/dishook` (after Pages setup)
2. Click the **+** button
3. Paste Discord webhook URL
4. Start managing webhooks!

### Local Development

```bash
git clone https://github.com/Artemishich/dishook.git
cd dishook
python -m http.server 8000
open http://localhost:8000
```
